# 诊所检查项目退项与费用调整系统

医生取消检查或设备故障导致项目无法执行时，收费台按**具体项目**办理退项；患者可清楚看到**退了哪项、账单如何变化、不能退的原因**。

- 后端：Rust + Axum + SQLx（SQLite，金额一律以“分”存储）
- 前端：Svelte 5 + Vite（后端直接托管构建产物）
- 保险 / 支付渠道回执：本地模拟（回执号 `INS-/CSH-/WXP-/ALP-`）

## 一键启动

```bash
./start.sh          # 首次运行自动装依赖、构建前端、启动服务
# 打开 http://localhost:3000
```

|---|---|---|
| `doctor` | 医生 | 标记项目已执行、取消医嘱、标记设备故障 |
| `cashier` | 收费员 | 开账单、办理退项 |
| `reporter` | 报告处理员 | 签发报告、作废报告 |
| `admin` | 管理员 | 全部权限 |

## 验证（自动化测试）

```bash
cargo test
```

覆盖需求要求的全部场景（`tests/api_tests.rs`）：

1. **部分执行**：账单含已执行/已出报告项目时，退项只处理可退部分，其余逐项给出跳过原因
2. **套餐拆分**：套餐价按项目原价比例分摊（最大余数法），各项目应付合计严格等于套餐价，退款按分摊价计算并保留明细
3. **混合支付退款核对**：医保+自费混合支付按原付款构成比例拆分退款，各渠道累计退款不超过原付款、合计精确到分
4. **岗位越权拦截**：未登录 401；医生/报告员退款、收费员签发/作废报告等一律 403
5. **重复退项**：同一项目重复退项只成功一次（状态机 + `refund_items.bill_item_id` 唯一约束双保险）；同一幂等键重放返回原退款单
6. **报告联动**：已出报告项目不可退、作废后只回到“已执行”（绝不回到未执行）；退款单 ↔ 报告作废记录双向可查
7. **总额上限**：任何调整都不能让总退款超过原付款（逐渠道余额校验 + 账单总额校验）

## 业务规则

- 每个检查项目展示：执行状态（待执行/已执行/已出报告/已退项）、原价、优惠分摊、可退金额
- 退款原因：医生取消检查 / 设备故障无法执行 / 患者要求退项 / 报告作废后退款
- 套餐项目：套餐价按原价比例分摊到各项目，分摊差额即“优惠分摊”，退项按分摊价退
- 混合支付：按账单**剩余可退余额**（初始即原付款构成）比例拆分退款，逐渠道保证不超原付款
- 已出报告的项目：不能改成未执行；需报告处理员先作废报告，收费台再以「报告作废」原因退款，退款单与作废记录互相引用
- 所有关键操作写入审计日志（操作人、岗位、动作、明细）

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/login` | 登录（返回 Bearer token） |
| GET | `/api/bills` / `/api/bills/{id}` | 账单列表 / 详情（含可退判定与原因） |
| POST | `/api/bills` | 开账单（单项 + 套餐模板 + 支付构成） |
| POST | `/api/bills/{id}/refunds/preview` | 退款试算（收费员） |
| POST | `/api/bills/{id}/refunds` | 办理退款（收费员，支持幂等键） |
| POST | `/api/items/{id}/execute` | 标记已执行（医生） |
| POST | `/api/items/{id}/flag` | 取消医嘱 / 设备故障标记（医生） |
| POST | `/api/items/{id}/report` | 签发报告（报告员） |
| POST | `/api/reports/{id}/void` | 作废报告（报告员） |
| GET | `/api/refunds` / `/api/refunds/{id}` | 退款记录 / 详情（计算明细、渠道回执、关联作废报告） |
| GET | `/api/reports` | 报告记录（含关联退款单号） |
| GET | `/api/bills/{id}/audit` | 账单操作日志 |

## 目录结构

```
├── src/            # Rust 后端
│   ├── refund.rs   # 退款引擎：可退判定、支付构成拆分、幂等事务

│   ├── handlers.rs # API 处理器（RBAC 在处理器入口强制校验）
│   └── db.rs       # 连接池 / 迁移 / 种子数据 / 回执模拟
├── migrations/0001_init.sql
├── tests/api_tests.rs
├── frontend/       # Svelte 前端
└── start.sh        # 一键启动
```
