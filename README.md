# 诊所检查项目退项与费用调整系统

医生取消检查或设备故障导致项目无法执行时，收费台按**具体项目**调整费用；
患者能看清退了哪项、账单如何变化。后端 Rust + Axum + SQLx + SQLite，
前端 Svelte，保险冲账与支付退款回执为本地模拟。

## 一条命令启动

```bash
./run.sh            # 构建前端+后端并启动在 http://localhost:8080
./run.sh --reset    # 同时清空演示数据库重新播种
```

打开 http://localhost:8080 ，在登录页选择岗位（本地演示令牌）：

| 岗位 | 令牌 | 权限 |
| --- | --- | --- |
| 李医生 | `tok-doctor` | 登记执行（含部分执行）、登记取消（医生取消/设备故障） |
| 王收费 | `tok-cashier` | 办理退项、查看账单与计算明细 |
| 赵报告 | `tok-report` | 出具报告、作废报告（联动退款） |
| 张三（患者） | `tok-patient` | 只读本人账单、退款与报告追查 |

## 业务规则

- **项目账单**：每个检查项目显示执行状态、原价、优惠分摊、成交金额、可退数量与可退金额。
- **部分执行**：可退数量 = 总数量 − 已执行 − 已退；只处理可退部分。
- **套餐拆分**：套餐父行只展示，退项必须落到子项；套餐价按子项原价比例分摊到子项，
  退子项时按其分摊成交价退款（套餐优惠不退回）。
- **混合支付**：退款按账单原始 **保险/自费付款构成比例**（基点整数运算）分别退回；
  保险走「冲账」、自费走「原路退回」，均出具模拟回执。
- **优惠不退**：实退 = 成交单价 × 数量，原价退款额与扣减的优惠分摊在明细中并列展示。
- **报告联动**：已出报告的项目不能改成未执行、不能直接退款；
  收费员提交后退款单进入 `AWAITING_VOID`，报告员作废报告后退款自动完成，
  `refunds.report_void_id` 与 `report_voids.refund_id` 双向外键可相互追查。
- **防重与上限**：同一项目重复退项只成功一次（待作废申请也占用名额）；
  任何调整都不能使总退款超过原付款，且分渠道退款不超过该渠道原付款；
  计算过程完整保存在 `refunds.calc_detail` JSON 中。
- **岗位 RBAC**：所有写接口在提取器层校验岗位，越权返回 403；
  业务规则冲突返回 422；患者只能访问本人账单。

## API 摘要

| 方法 路径 | 岗位 | 说明 |
| --- | --- | --- |
| `GET /api/bills/:id` | 全部（患者限本人） | 账单聚合视图：项目树、付款构成、调整前后金额 |
| `POST .../items/:item/execute` | 医生 | 登记执行数量（可分次→部分执行） |
| `POST .../items/:item/cancel` | 医生 | 登记取消原因 `DOCTOR_CANCEL`/`EQUIPMENT_FAULT` |
| `POST .../items/:item/issue-report` | 报告员 | 出报告 |
| `POST /api/bills/:id/refunds` | 收费员 | 办理退项（无报告即时完成/有报告挂起待作废） |
| `POST /api/reports/:id/void` | 报告员 | 作废报告并完成挂起退款 |
| `GET /api/refunds/:id/trace` | 全部（患者限本人） | 退款 ↔ 报告作废双向追查 |

## 数据模型

金额一律以**分**存储（INTEGER）避免浮点误差。核心表见 `migrations/0001_init.sql`：
`bill_items`（套餐父子行 + 数量/已执行/已退）、`bill_payments`（保险/自费构成）、
`refunds`（金额拆分 + `calc_detail` 计算明细 + 回执号 + 作废关联）、
`reports` / `report_voids`。

## 验证

```bash
cargo test
```

覆盖（`tests/api.rs` 端到端 HTTP + `tests/calc.rs` 计算边界）：

1. **岗位越权拦截**：医生退项 403、收费员取消/作废/出报告 403、患者退项 403、无令牌 401；
2. **部分执行**：血常规 2 项已执行 1，退 2 项被拦、退 1 项成功、再退被拦；
3. **套餐拆分**：父行退项被拦，心电图/肌钙蛋白子项分别按分摊价退款；
4. **混合支付核对**：CT 实退 27000 = 保险 16800 + 自费 10200（56/34 万付款构成），
   并校验保险冲账/自费退款回执；
5. **报告拦截与作废**：已执行已出报告不可取消/退款；未执行但已出报告的项目走
   挂起→作废→完成，双向追查记录完整，重复作废被拦；
6. **退款上限**：累计退款 72000 ≤ 原付 90000，分渠道（保险 44799 ≤ 56000、
   自费 27201 ≤ 34000）均不超限；计算单测覆盖总额超限拦截、保险溢出转自费、尾差归自费。
